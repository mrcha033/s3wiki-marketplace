# Princeton WordNet verb data

`english-verbs-wordnet-index.txt` and
`english-verbs-wordnet-exceptions.txt` are derived from the `dict/index.verb`
and `dict/verb.exc` files in Princeton WordNet 3.1. The index content is
unchanged except for trailing-whitespace normalization.
`english-nouns-wordnet-exceptions.txt` is copied from `dict/noun.exc` in the
same release and is used only for irregular-plural subject detection:

- Source: <https://wordnetcode.princeton.edu/wn3.1.dict.tar.gz>
